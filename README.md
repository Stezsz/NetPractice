# NetPractice – 42 School Project

The **NetPractice** project is a practical introduction to the world of networking. It consists of a series of exercises that require configuring network interfaces, subnets, and routing tables. The goal is to solve various networking puzzles, ensuring that all devices within a given architecture can communicate effectively while respecting the constraints of IPv4 addressing.

## Main Objectives

* Understand the fundamentals of the **TCP/IP stack**.
* Master **IPv4 addressing** and subnet masking (CIDR and decimal).
* Configure **routing tables** to direct traffic between different networks.
* Solve complex networking scenarios involving **Routers**, **Switches**, and end-host devices.
* Differentiate between private and public IP address ranges.

## Key Features

* **Subnetting Skills:** Calculating network addresses, broadcast addresses, and usable host ranges based on mask prefixes.
* **Routing Logic:** Defining "Next Hop" and destination rules to ensure packets reach their target across multiple network hops.
* **Progressive Difficulty:** 10 distinct levels covering:
    * Simple point-to-point connections.
    * Private network configurations.
    * Complex internetworks with multiple routers and overlapping subnets.
* **Problem Solving:** Identifying and fixing configuration errors such as IP conflicts, incorrect masks, or missing default gateways.
* **Visual Simulator:** Working with a web-based interface to validate real-time connectivity through "pings" between devices.

## Conclusion

The **NetPractice** project is a crucial milestone for understanding how the internet and private networks function at a low level. It provides the theoretical and practical foundation necessary to grasp how data is encapsulated and routed across the globe. Completing this project ensures a solid command over the addressing rules that govern modern network communications.
